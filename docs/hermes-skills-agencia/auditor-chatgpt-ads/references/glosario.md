# Glosario corto

- **oaiq** — cola/SDK del Measurement Pixel de OpenAI Ads en el navegador.
- **Pixel ID** — ID de la data source en Ads Manager (Conversions).
- **oppref / __oppref** — id de click del anuncio; el pixel lo guarda en cookie first-party.
- **measure** — llamada `oaiq("measure", evento, data, options)` que registra la conversión.
- **lead_created** — evento estándar de lead (`type: customer_action`).
- **event_id** — id único para deduplicar browser + CAPI.
- **CAPI** — Conversions API server-side.
- **CMP** — banner de cookies / Consent Management Platform.
- **GTM Preview** — depurador de Google Tag Manager antes de publicar.
