# Roles de ángulo RSA (no sinónimos)

Al generar 15 titulares, reparte roles:

1. Keyword / intención de búsqueda
2. Problema / dolor
3. Beneficio principal
4. Beneficio secundario
5. Oferta / gancho
6. Prueba (dato, años, casos) — solo si está en brief
7. Diferenciador
8. Para quién (ICP)
9. Objeción → respuesta corta
10. Urgencia / plazo — solo si es real
11. CTA directo
12. Local / España / ciudad — si aplica
13. Servicio concreto (SEO, Ads…)
14. Resultado deseado
15. Variante keyword long-tail

Descripciones (4): problema+solución | oferta+CTA | prueba+CTA | keyword+beneficio+CTA
