# Warren — uso ético

3 leyes: resisten lo detectado; no resisten lo no detectado; creen lo que concluyen solos.
Adicciones: esperanza, importancia, certeza, comprendido, secreto, tener razón, enemigo común.
Ventriloquia: mostrar/preguntar, no imponer + gritar la conclusión.
Prohibido: gaslighting, mentiras, falsa escasez, testimonios falsos.
